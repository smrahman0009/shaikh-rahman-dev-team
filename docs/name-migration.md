# SR Dev Team naming

The installed skill is now `$sr-dev-team`, its display name is SR Dev Team,
custom role IDs use `sr_`, and new toolkit installations live in `tools/sr-dev-team`.
The public repository remains `shaikh-rahman-dev-team` to show the author's full name.

Existing private task ledgers retain the `.startup-team` directory and schema, so
saved projects continue to open without a data migration. That directory is not
the skill invocation. Original prompts and archived review evidence retain their
historical wording and paths; they are evidence, not current operating instructions.

In this workspace the old skill and role folders were renamed, so two skill names
are not installed side by side. For another previous installation, review and
replace the old installed skill/role definitions deliberately. The installer never
deletes or overwrites differing user files. Reload the Codex session to refresh
the skill list, then use `$sr-dev-team`.
